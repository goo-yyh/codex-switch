# 界面与交互规范

更新：2026-09-16。产品结构以配置为单位：**一个名称 + 一个 Key + 多个模型**。

## 首页

- 「我的配置」采用响应式卡片网格：常规窗口两列，窄窗口一列，宽窗口三列。顶部显示总数及新增入口；空状态仅保留一个新增入口。
- 每张卡片显示厂商 Logo、配置名称、厂商、模型数量及模型标签。底部显示未选择／已选择／使用中状态，以及编辑、删除入口。过多模型用数量和悬浮完整列表提示。
- 复选框可同时勾选多个厂商的配置，显示已选配置和模型总数。
- 关闭时勾选作为下次开启的选择；开启期间勾选立即应用，失败保留原选择。
- 底部连接控制区始终可见，集中放置总开关、已选配置／模型数量和「打开 Codex」。开关是唯一开启入口，不再显示重复的配置应用按钮。
- 开启至少需要一个选中配置，开启期间不能取消最后一个选中项。关闭总开关恢复原配置。开启时禁止新增、编辑、删除并展示提示，后端同样拦截。
- 切换后旧会话的后续请求也使用当前配置。Codex 运行时提示重新打开刷新模型列表，必须确认正常重启，不强制结束请求。

- 顶部工具栏保留品牌，文档与设置均显示图标和文字。版本与项目说明放在设置页，首页去掉重复页脚。

## 新增与编辑

- 配置页由「连接信息」「模型选择」「高级设置」三张独立卡片组成，标题样式统一，高级设置始终展开。
- 新增时选择厂商，设置配置名称，填写一个 Key，勾选 1–20 个模型。编辑时只显示当前厂商 Logo 与名称，不能更换厂商；后端同样拒绝修改厂商。
- 所有厂商始终显示名称字段。默认厂商名称、厂商-2、厂商-3，按已有同厂商配置数编号并跳过全局重名。手动输入的名称不随厂商切换覆盖。
- 配置名称忽略首尾空白和大小写进行全局唯一性检查；前后端双重校验，编辑自己不冲突。
- 模型列表不显示「已配置」标记。首个勾选的模型为默认，其他已选模型可「设为默认」；取消或删除默认模型后，按剩余选择顺序使用第一个模型。
- 自定义模型提供删除入口，取消勾选与删除分开处理。新增 ID 去除首尾空格后不能与当前列表中的 ID 重复；不同配置可以使用相同模型。
- 添加与编辑都支持模型多选。编辑 Key 留空时复用该配置原密钥，地址改变则必须提供新 Key。
- 主操作只有「保存配置」：逐个验证后保存一个配置并回到首页，不自动勾选、应用或启动 Codex。
- 表单滚动，保存区固定。验证期间锁定导航和输入，允许取消。全部验证通过才保存；取消与保存完成的竞态明确告知状态。
- Codex 中显示 `${配置名称}-${模型}`。表单不再常驻显示命名示例、模型验证原理和「已配置」释义，保留字段标签、状态标记与必要的校验反馈。

## 路由与旧数据

- 配置有稳定 ID，当前版本只指向一个凭据标识；每个模型有独立路由标识。
- 历史模型标识映射到当前配置：同一配置中仍有原模型则使用其最新版本，否则使用当前默认模型。不加载历史 Key 或调用旧地址。
- 关闭后可删除配置和勾选。历史修订记录及凭据暂不自动清理，但后台不再使用它们；重新开启按当前选择生成目录。
- 旧版单模型连接逐条迁移，不推断不同条目的 Key 相同；自动消除重名，保留模型路由及凭据标识。

## 视觉

灰白背景、Ant Design 主蓝色（#1677FF）按钮与白色文字，开关和复选框统一蓝底白色指示，选中卡片使用细蓝边框。正文保持清晰深灰，保留开关 App 图标与五家厂商品牌 Logo。官网示意与首页的配置多选结构保持一致。

## 测试边界

浏览器预览只使用页面内存。单元测试使用模拟凭据、内存数据库或临时目录，不操作真实 Codex App、真实配置、Keychain 或真实模型服务。构建不代表原生 App 实机验证。
