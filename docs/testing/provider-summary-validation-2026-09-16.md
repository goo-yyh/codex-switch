# 默认摘要压缩与远程开关验证

2026-09-16，使用仓库 `.env` 的 Key，直接调用当前五家预设的默认模型。未启动或修改真实 Codex App、CLI、app-server、配置、登录态或会话。浏览器设置页仅使用内存预览。

## 产品行为

- 设置 → 通用设置 → **远程上下文压缩**，默认关闭。关闭时保留普通第三方 provider 身份，由 Codex 使用普通模型请求生成摘要并管理历史。
- 开启时沿用 CC Switch 的 `name = "OpenAI"` 配置标记，由客户端选择其远程压缩协议。本项目不主动拼造远程请求，不把开关硬编码成调用 `/responses/compact`。
- 原生 Responses 透传新版 `/responses` + `compaction_trigger`、压缩项及 JSON/SSE 返回；旧版独立 `/responses/compact` 仍按对应地址转发。
- Chat 连接收到 `compaction_trigger` 或不透明 `compaction` 历史时明确报错，提示关闭远程开关或使用支持协议的 Responses 服务，避免上游转换器静默丢弃这些项。普通摘要文本和 compaction 元数据仍走普通桥接。未移植尚未合并的 CC Switch PR #5536，也不制造假加密压缩项。
- 开关保存后下次开启 Codex Switch 时生效；运行中的 Codex 可能需要重新加载配置。开启期间界面提示先关闭 Codex Switch 再修改设置。设置适用于所有选中的连接，不自动改变连接协议，不承诺远程失败后自动切回摘要。

### 验证方法

1. 每家生成新的 129,841 字节、97 条消息的合成项目历史。六个随机校验值分散在 assistant 历史前、中、后段，另有一条被后续覆盖的旧 release_code。
2. 原始历史加问句，验证六个最新值全部可找回。
3. 从同一份原始历史重新开始，追加固定 `openai/codex rust-v0.149.0` 的 `SUMMARIZATION_PROMPT`，通过普通模型请求生成文本摘要。基线答案不加入这次输入。
4. 丢弃原始历史，只将 Codex `SUMMARY_PREFIX`、生成的摘要和新问题送入新请求。没有 previous_response_id、compaction_trigger 或 encrypted_content，也没有补回随机答案。
5. 续接必须精确找回全部六个值，状态必须完成，且供应商报告的输入 token 数必须减少。单纯返回 200、生成一段摘要或压缩字节减少不算通过。

测试专用提示词、前缀和 Apache-2.0 许可证保存在 `crates/core/tests/fixtures/codex-compact/`。该方法比保留原始用户消息更严格，但只模拟“摘要后续接”，并未完整重现 Codex 的用户历史保留、工具历史、自动触发和持久化策略。

### 证据与复跑

- [结构化脱敏回执](provider-summary-validation-2026-09-16.json)：时间、端点、模型、每次用量与耗时、输出哈希、事实校验和失败记录。
- 本机原始脱敏回执：`reports/local/provider-compact-1789545887.jsonl`，Git 忽略、权限 0600。
- 复跑：`pnpm test:providers:summary --all`，或仅指定供应商，例如 `pnpm test:providers:summary minimax`。会产生真实服务费用。
- 普通 CI/测试不运行这条命令，不读取 `.env`。报告不保存 Key、原始历史、摘要正文、推理正文或原始响应。
- 超时请求未返回用量，不能按零费用解释。已返回用量的合计保存在结构化回执中，不用 token 数推断账单金额。

## 本地验证

- React 测试 39 项通过，覆盖开关默认关闭、保存开启、离开再进入回显、关闭再保存，以及不自动启用 Codex。
- Rust 核心测试 77 项通过；集成测试覆盖已有 14 项加本轮 3 项：普通摘要桥接与 remote 输入拒绝、Remote V2 JSON 透传、Remote V2 SSE 透传。配置开关开启/关闭和精确恢复由已有集成用例验证。
- 校验脚本的 2 项离线测试通过：精确召回与完成状态判定、随机答案不会泄漏进用户历史或续接问题。
- Clippy 严格检查、TypeScript 检查、桌面前端构建通过；CC Switch 固定来源校验通过。
- 浏览器预览实际检查默认关闭、开启保存、离开重进仍开启、关闭保存及页面排版，最后恢复关闭。预览不证明原生系统持久化或 Codex 加载行为。

## 验收边界

本轮已经证明四个具体默认模型支持这一合成样本的普通摘要生成及摘要续接；智谱仍有请求超时问题。结论不覆盖同厂商所有模型或套餐，不覆盖百万 token 极限、多次连续压缩、工具/图片历史或真实编码任务。

远程开关和转发行为通过源码及隔离集成验证，**没有新增 remote V2 供应商支持性结论**。真实 Codex App 内的触发、配置加载、历史替换及重启恢复依照用户要求未执行，不能据本报告宣称 App 端到端验收通过。
