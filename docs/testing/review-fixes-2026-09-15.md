新增核心模块：

- `crates/core/src/connections.rs`：可注入的凭据接口、复用范围与保存补偿。
- `crates/core/src/activation.rs`：产品原生命令实际调用的开启协调层，测试使用无网络的 Runtime 替身。

更换密钥也创建新的连接身份，避免改变已有任务的凭据。数据库保存失败时清理新建凭据；旧身份只更新元数据，不重写其密钥。

## 同步完成的产品优化

- “仅验证并保存”不再设为默认、不修改 Codex 配置、不打开应用。
- 恢复状态明确显示“连接待恢复”，增加“仅恢复连接”，保留单独打开/正常重启入口。
- Codex 未运行且没有请求时清理不再被当前配置或恢复基线引用的自动生成 catalog；解析失败时保留文件。
- 窗口重新获得焦点时刷新状态；操作期间不触发该刷新。
- 官网与应用显示版本、渠道、仓库、下载信息集中到 `packages/product-info/product.json`。
- 通过构建变量 `VITE_PUBLIC_DOCS_URL` 配置独立 HTTPS 文档入口；未配置时使用源码文档，不猜测正式域名。
- 官网改为“内置五家服务预设”，兼容页区分既有供应商检查与真实 App 验证。
- 更新快速开始、开关恢复、兼容性、开发、更新日志与测试方案。

- 未调用真实模型服务；此前供应商回执没有被当作本次修复后的重测结果。
- 没有运行 Windows 实机验证、正式签名公证或公开发布；没有提交、推送或上传 GitHub。
