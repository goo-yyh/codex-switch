MiniMax 与 Kimi 的预设地址 / 模型对照了官方资料：[MiniMax 模型列表](https://platform.minimaxi.com/docs/api-reference/models/openai/list-models)、[Kimi 模型列表](https://platform.kimi.com/docs/api/list-models)。文档列出的模型不代表这枚 Key 的套餐具备相同权限。Kimi 尚需确认 Key 属于开放平台还是 Coding 套餐；没有根据 Key 内容猜测套餐，也没有盲试其他计费端点。

**结论：千问、MiniMax、DeepSeek 的上述四项接口检查通过。智谱仅文本通过，Kimi 当前未通过。** 官方 Responses 中转站尚未提供专用实测凭据，仅实现转发及离线边界检查。
