# 托盘快速开关与配置切换

> 恢复与配置版本规则随后按[统一当前配置](2026-09-16-current-config.md)更新；开启期间勾选直接应用，禁止修改配置内容。

## 行为

- 开启首页所选配置（支持多个），或关闭并恢复本次开启前的配置。
- 「切换并开启配置（单选）」列出全部已保存配置及模型数量。一次点击应用该配置的全部模型，并同步首页选择；当前关闭时同时开启。
- 勾号来自已应用快照，编辑但尚未应用的配置不会误标为当前版本。
- 提供恢复后台连接和打开主界面入口；无配置时提示先添加。
- 托盘与首页共享操作锁及开启、恢复代码。验证或应用过程中拒绝排队切换；失败打开主界面显示原因，恢复冲突沿用原确认弹窗，不强制覆盖。
- 正在运行的 Codex 不会被自动重启，菜单及主界面提示正常重新打开后生效。

## 一致性

快速切换先解析目标模型和凭据，不提前修改首页选择。激活提交阶段在同一 SQLite 事务内更新默认模型、端口、已应用快照、历史路由和首页选择；任一步失败整体回滚。配置文件及路由仍使用已有激活事务机制。

主界面通过 Tauri 事件刷新，打开窗口时也刷新。托盘反馈保留到下次快照读取，窗口隐藏时的错误不会直接丢失。快照刷新同时重建菜单，使新增、编辑、删除及应用后的菜单保持同步。
