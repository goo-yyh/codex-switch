# 精简首页与服务商 Logo

## 最终实现

- 首页采用单列连接列表，点击即选择；编辑和删除位于各行旁边。
- 一个启用开关、一个「开启并打开 Codex / 打开 Codex」按钮，移除重复详情与说明。
- 首次使用直接选服务商，表单提供六个服务选项；字段区域滚动，提交区固定可见。
- 设置按启动与应用、配置与恢复分组。
- 五家 Logo 使用 Lobe Icons 静态 SVG 1.95.0，本地打包；qianwen 对应 Qwen，其他 ID 对应各自品牌。Kimi 使用深色底板显示原图中的白色 K。
- 官网中的产品示意、服务商列表、快速开始文档同步。

## 验证

- 17 项 React 单元测试通过，包括首页选择、空状态直接添加、启用后运行中的 App 必须经过重启确认。
- TypeScript / Astro 检查通过。
- 官网静态构建和 15 页链接与锚点检查通过；密钥扫描通过。
- 浏览器检查五家图标匹配与加载，Kimi 浅色背景显示、添加与保存、官网开关示意。
- 600×560 App 预览中页面宽度为 600，无横向溢出；表单提交按钮底部为 474.5px，在窗口内可见。首页选择与打开按钮同屏可见。
- 390px 官网预览无横向溢出，五家服务 Logo 均加载成功。

## 边界

本轮只修改界面、品牌资源、文档与打包资源；未修改 Rust 路由与配置恢复逻辑。预览为内存模拟，不调用真实模型服务、不访问系统凭据、不修改真实 Codex 配置，也未启动真实 Codex App。
