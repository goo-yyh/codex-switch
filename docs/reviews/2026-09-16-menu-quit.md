# 精简系统菜单与托盘退出

## 变更

- macOS 菜单不再显示撤销、重做、剪切、复制、粘贴、全选及其分隔线。
- 编辑命令仅作为隐藏快捷键保留，避免删除原生菜单角色后无法通过 Cmd+V 填写 API Key。使用 AppKit 的 `setHidden` 和 [`allowsKeyEquivalentWhenHidden`](https://developer.apple.com/documentation/appkit/nsmenuitem/allowskeyequivalentwhenhidden)，在 Tauri 安装应用菜单之后、主线程 setup 中执行。
- 托盘菜单增加「退出 Codex Switch」。现有托盘组件默认支持右键打开菜单，保留左键操作习惯。
- 托盘退出与系统菜单退出统一调用设置页的 `quit` 命令，经过操作锁、正在使用的连接检查、原配置恢复和路由关闭后退出。
- 恢复失败或 Codex 仍在使用连接时不会退出；反馈保存在应用状态中并打开主窗口显示，窗口恢复焦点时也可读取。
