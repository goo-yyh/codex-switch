# 模型选择与批量配置

## 实现

- 五家厂商分别提供模型候选；清单与官方出处见 `packages/provider-registry/README.md`。
- 新增连接支持勾选多个模型（1–20 个），共用本次输入的密钥和地址。支持自定义模型、去重和默认模型标识。
- 编辑已有连接支持模型下拉与自定义 ID；不迁移用户已有模型值。
- `save_connections` 逐个验证，全部通过后才写入凭据及连接。连接元数据采用单个 SQLite 事务，凭据或数据库失败时清理本次新增凭据；清理失败时返回待处理的连接标识。
- 原有连接及其凭据不受批量新增影响。保存后的模型分别显示在首页，可独立选择。仅保存不会开启路由或打开 Codex。
- 官网演示默认模型、快速开始和国内模型文档同步更新；历史兼容性回执继续保留原型号，未将旧测试结论套用到新型号。

## 验证

- 前端 30 项测试通过，包含五家厂商映射、切换厂商清空密钥与选择、自定义模型去重、空选择拦截、批量失败重试、验证锁定、取消竞态、历史模型保留、启用失败后不重复建批次。
- Rust 核心 62 项测试通过；新增覆盖批次参数校验、数据库事务回滚、部分凭据写失败清理、保留旧凭据、共享密钥保存、失败模型定位及取消竞态。仅用内存凭据库、内存数据库及模拟验证回执。
- TypeScript、Astro 检查通过；workspace Clippy（`-D warnings`）通过。顺带清理 macOS 退出函数的一处多余 `return`，无行为变化。
- 官网构建、15 页本地链接检查和密钥检查通过。
- 浏览器内存预览确认批量保存、首页切换与编辑下拉。600×560 最小窗口中模型列表可滚动，提交按钮保持可见。
- 原生构建仅生成安装包，不安装、不启动。未运行真实 Codex App，未修改真实 Codex 配置或系统凭据，未调用真实供应商服务。

模型 ID 来自官方文档不等于完整模型兼容性验证；新增型号的实际 API 权限与工具调用能力仍需后续独立验证。
