**一般保留预设即可；修改前先关闭服务。** 一个配置可选 1–20 个模型，多个配置可以同时启用。

## 选择与默认模型

勾选要使用的模型。列表没有时，在「其他模型 ID」中输入服务商提供的准确 ID，点击「添加模型」。

[![模型多选、默认标记与编辑入口](/screenshots/models.png)](/screenshots/models.png)

_截图为应用浏览器预览，使用示例数据，连接状态为模拟。点击图片可放大。_

鼠标移到模型行，或用 Tab 聚焦，显示「编辑」「设为默认」。首个选中的模型默认优先使用；也可手动设为默认，移除后由剩余的第一个模型接替。

## 调整模型能力

点击模型旁的「编辑」。修改仅用于当前配置的这个模型，**确认弹窗后，还要点击「保存配置」**。

[![模型能力弹窗中的上下文长度、思考档位和其他设置](/screenshots/model-options.png)](/screenshots/model-options.png)

| 设置             | 何时调整                                                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 上下文长度       | 内置预设通常取模型容量的 80%，预留余量。自定义模型或套餐额度不同，再按实际容量调整。填大不会扩大模型能力，压缩时机由 Codex 决定。 |
| 思考档位与默认值 | 保留该模型的预设；自定义时用英文逗号分隔，只填服务支持的值，默认值必须在列表内。                                                  |
| 图像输入         | 模型确实支持图片时再声明支持，不确定时保留默认。                                                                                  |
| 并行工具调用     | 按服务能力设置，不确定时保留默认。                                                                                                |
| 地址与接口       | 仅当这个模型需要不同的地址或接口时覆盖，否则继承配置。                                                                            |

已有配置的上下文值不会随预设更新自动改变；保存和开启也不会再次乘以 80%。思考默认值按模型和套餐分别设置，不统一使用同一档位。

逐模型地址仍使用此配置的 Key。更换地址需重新填写 Key；需要不同密钥时，新建另一个配置。地址用法见[连接模型服务](/docs/providers/#地址怎么填)。
