**开启前自动备份，关闭后自动恢复。** 关闭窗口只会收起到托盘，不等于关闭服务。

## 开启并使用模型

首页勾选一个或多个配置，打开底部「Codex Switch」开关，再从系统中打开 Codex App。仅勾选配置不会开启服务。

[![选择配置后开启 Codex Switch](/screenshots/selected.png)](/screenshots/selected.png)

_截图为应用浏览器预览，使用示例数据，连接状态为模拟。点击图片可放大。_

Codex 已在运行，或模型列表没有更新时，先完成当前任务，再正常退出并重新打开。Codex Switch 不会自动重启 Codex。

## 关闭并恢复

开启后会显示锁定蒙层。关闭图中的服务开关，即可自动恢复本次开启前的配置，无需再次确认；随后可修改配置和设置。

[![关闭蒙层中的服务开关，恢复原配置](/screenshots/enabled.png)](/screenshots/enabled.png)

Codex 的登录、会话与历史文件保持原样。已经运行的 Codex 可能仍使用旧配置，正常退出再打开后才会读取恢复结果。

更换模型配置时，按 **关闭服务 → 修改或重新勾选 → 开启服务 → 重新打开 Codex** 操作。旧会话的后续请求也会使用当前配置。

## 托盘快速操作

| 操作                         | 作用                                                                             |
| ---------------------------- | -------------------------------------------------------------------------------- |
| 选择配置（可多选）           | 与首页同步选择，不自动开启。macOS 支持连续勾选而不关闭菜单。服务开启时不可修改。 |
| 开启 Codex Switch / 关闭服务 | 启用所选配置，或恢复原配置。                                                     |
| 打开面板                     | 重新显示主窗口。                                                                 |
| 退出应用                     | 完全退出。先正常退出正在使用连接的 Codex，再退出 Codex Switch。                  |

## 遇到异常时

- **应用意外退出**：重新打开 Codex Switch，先关闭服务恢复原配置，再按需开启。
- **配置被其他程序修改**：恢复前自动另存副本；如果另存或恢复失败，保留文件并显示错误。
- **未找到 Codex**：安装应用后，在「设置 → Codex App」点击「重新检测」。
