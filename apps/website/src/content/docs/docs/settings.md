先关闭服务，再点击首页底部卡片右下角的「设置」。**开关自动保存，下次打开保留上次状态。**

## 远程上下文压缩

**默认关闭，建议保持关闭。** 关闭此开关不等于禁用所有压缩，Codex 仍可通过普通模型请求生成摘要。

仅在服务明确支持远程压缩时开启；不支持时可能失败，不保证自动回退。此设置适用于所有选中配置，下次开启服务生效，已经运行的 Codex 可能需要重新打开。

## 登录电脑时启动

默认关闭。开启后，登录系统时启动 Codex Switch；无需每次手动打开应用。

## 中英文切换

顶部「文档」左侧可切换语言，页面、弹窗和托盘菜单同步更新，下次打开沿用选择。文档按钮打开对应语言的教程。

## 应用检测与退出

「Codex App」显示安装和运行状态，安装或移动应用后可点击「重新检测」。「配置位置」显示当前操作的配置文件。

关闭窗口会保留后台连接。需要完全退出时，先正常退出 Codex，再使用托盘「退出应用」或设置底部的退出按钮。恢复原配置只需[关闭服务](/docs/switch/#关闭并恢复)。
