## 远程上下文压缩

**默认关闭，建议不开启。** 由服务端压缩上下文，需要目标服务支持对应协议。

| 状态 | 作用                                                                                                          |
| ---- | ------------------------------------------------------------------------------------------------------------- |
| 关闭 | 不启用远程压缩标记，Codex 可通过普通模型请求生成文本摘要并整理上下文。关闭此开关不等于禁用一切上下文压缩。    |
| 开启 | 启用远程压缩标记，由 Codex 客户端选择远程协议；本地网关按兼容范围转发。上游不支持时可能失败，不保证自动回退。 |

开关变化后**自动保存**：开启后下次打开仍开启，关闭后下次打开仍关闭，无需另点保存。请先关闭首页 Codex Switch 总开关再修改，下次开启时生效；已经运行的 Codex 可能需要重新加载配置。

此偏好适用于所有选中的配置，不按模型分别设置。普通文本摘要生成与远程压缩是不同能力：目前的[最小摘要验证](/docs/compatibility/#普通摘要生成验证)只证明指定模型能够返回摘要，不能证明它支持远程压缩。

## 登录电脑时启动

默认关闭。开启后在登录系统时启动 Codex Switch。它是应用的启动偏好，与远程压缩开关分别保存。

关闭窗口仍保留托盘和后台连接；需要完全退出时使用页面底部「完全退出 Codex Switch」或托盘菜单。先完成任务并正常退出 Codex，详见[关闭与恢复](/docs/switch/)。

## Codex App 与配置恢复

「Codex App」显示检测到的应用和运行状态；安装或移动应用后可点击「重新检测」。

「配置位置」显示当前操作的 `config.toml` 路径。通常为 `~/.codex/config.toml`，设置 `CODEX_HOME` 时以实际显示为准。「恢复开启前的配置」用于恢复备份；正常使用时关闭首页总开关即可恢复。遇到外部修改冲突，先保留当前版本，再按提示恢复。

应用只改写配置文件，不改写登录与会话文件。备份、异常恢复和旧会话规则见[开启、关闭与恢复](/docs/switch/)。
