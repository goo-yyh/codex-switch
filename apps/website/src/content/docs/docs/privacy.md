## 本机保存

- 配置名称、模型列表、地址及设置保存在本地 SQLite。
- API Key 保存在系统凭据库，不返回到前端展示、不写进模型目录。
- 配置恢复记录和本地访问令牌存放在应用自己的数据目录及所投影的配置中。macOS/Linux 文件权限为仅当前用户读写。
- 第一版没有遥测、云端账户或集中请求日志。

## 网络请求

保存配置不会发送测试请求；只有点击「测试配置」时才会向所选服务商发送测试请求。正常使用时，提示词与工具相关内容发送给你选择的服务商。服务商密钥由本地路由加入请求，客户端头部不会原样转发。

本地路由仅绑定 `127.0.0.1`，请求需要随机访问令牌。公网 HTTPS 证书校验开启，上游重定向关闭。

## 开发用 .env

仓库根目录 `.env` 只供显式的供应商测试命令读取。它不被桌面前端、官网或发布包载入。仓库只提供不含值的 `.env.example`。

不要提交真实密钥、配置备份或完整请求内容。提交前运行 `pnpm check:secrets`。脚本只报告问题文件位置，不输出密钥。

## 删除数据

关闭 Codex Switch 后才能删除配置。删除会移除首页条目及勾选；重新开启时模型目录只包含当前配置。旧会话的模型标识会转到当前配置，后台不再读取历史 Key 或调用旧地址。

本地数据库和系统凭据库中的历史修订暂不自动清理，因此删除配置不等于彻底清除密钥。需要彻底清除本机数据时，应先关闭开关、退出 Codex 与 Codex Switch，再由用户清理应用数据目录及系统凭据库中的 Codex Switch 条目。卸载前请确认原配置已恢复。
