## 0.1.0 · 开发预览

- 新增简明的 Codex App 连接管理界面。
- 新增国内五家服务预设与自定义接口。
- 新增总开关、开启前备份、关闭精确恢复、外部修改冲突保护。
- 新增 Responses 转发与 Chat 文本、流、工具协议转换。
- 新增系统凭据库、模型路由别名、托盘、登录启动设置。
- 新增正常打开 / 重启入口，以及异常退出后的手动恢复。
- 新增独立官网、产品文档、离线测试及显式供应商测试命令。

### 2026-09-17 · 配置与文档更新

- 移除备用队列及路由保存入口，请求失败不再自动切换服务。
- 远程上下文压缩默认关闭，开关自动保存，重新打开保留状态；下次开启连接时生效。
- 连接页支持完整 URL，模型可独立覆盖地址、接口和能力。
- 新增普通摘要最小验证，每家默认模型仅发送一次请求，不启动 Codex 客户端。
- 更新 README 与文档站，加入真实界面截图、配置说明和 CC Switch 开源致谢。

以下为历史版本记录，当前行为以使用文档为准。

### 2026-09-15 · Review 修复

- 修复跨服务商或套餐地址复用旧密钥；修改密钥创建新路由，保留旧任务凭据。
- 修复流式工具历史补全、长命名空间工具名和并行调用参数转换。
- 修复验证期间离开页面与取消竞态；「仅验证并保存」不再切换默认连接。
- 新增开启失败补偿、独立凭据错误提示、仅恢复连接入口和过期模型目录清理。
- 统一产品发布信息，支持配置独立文档地址。
