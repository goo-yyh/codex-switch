macOS 用户可在「关于本机」中查看芯片：M1 及更新芯片选择 Apple Silicon，Intel 芯片选择 Intel。Windows 安装包适用于 **x64**。本次未提供 Linux 或 Windows ARM64 安装包。

Codex App 按钮链接到 OpenAI 官方下载源。[官方指南](https://learn.chatgpt.com/docs/app)现称其为 **ChatGPT 桌面应用**，登录后可选择 Codex。按本教程使用时，请同时安装两个应用。

### 校验安装包

下载与安装包同一版本的 [SHA256SUMS.txt](https://github.com/goo-yyh/codex-switch/releases/latest/download/SHA256SUMS.txt)，将计算结果与文件中对应名称的校验值比较：

```sh
# macOS：Intel 用户请替换为对应文件名
shasum -a 256 ~/Downloads/Codex-Switch_aarch64.dmg
```

```powershell
# Windows PowerShell
Get-FileHash "$HOME/Downloads/Codex-Switch_x64-setup.exe" -Algorithm SHA256
```

> 本次 Codex Switch 安装包没有发布者签名，macOS 应用未经 Apple 公证。Gatekeeper 或 SmartScreen 可能提示或阻止运行。请先确认下载来源并核对校验值；组织管理的设备可能不允许安装。

## 安装应用

若已安装旧版，先关闭 Codex Switch 服务，再正常退出应用。

### macOS

1. 下载与你的 Mac 芯片匹配的 `.dmg` 安装包。
2. 打开安装包，将 Codex Switch 拖入「应用程序」。
3. 从「应用程序」中打开 Codex Switch。

### Windows

1. 下载与你的系统匹配的安装程序。
2. 双击运行，按安装向导完成安装。
3. 从开始菜单打开 Codex Switch。

## 首次打开

使用前，准备好已安装的 [Codex App](https://learn.chatgpt.com/docs/app)，以及模型服务商提供的 API Key 和可用额度。

打开 Codex Switch 后，会看到下面的空配置页。点击中央「新增配置」，跟随[三步连接](/docs/quickstart/)完成设置。保存配置后，需要手动勾选配置并开启服务。

## 更新应用

应用会在后台检查正式版本。有新版本时，顶部语言按钮旁会显示蓝色下载图标和版本号；点击即可通过系统浏览器下载对应系统和架构的安装包，无需进入发布页面。不会自动安装或重启。

安装前先关闭服务，再正常退出 Codex 和 Codex Switch，按上述步骤安装新版。已有配置保留在本机，无需重新创建。

## 卸载应用

卸载前先关闭服务，恢复原有配置，再正常退出 Codex 和 Codex Switch。随后从「应用程序」或 Windows 的「已安装的应用」中卸载。

仅删除应用不会自动恢复配置，也不会清除系统凭据库和本地数据。
