## 打开 Codex

保存配置后，在首页勾选需要的配置并开启总开关，再从系统中打开 Codex App。服务开启后主界面显示蒙层，只保留「关闭服务」操作；修改配置、选择或设置前需先关闭服务。

## 配置更新后

Codex 界面的模型列表可能仍来自内存中的旧目录。请先完成当前任务，再正常退出并重新打开 Codex，以读取新的模型目录。关闭服务后恢复的原设置也可能需要重新打开才能读取。Codex Switch 不会因开启服务自动启动或重启 Codex。

## 关闭窗口与完全退出

关闭 Codex Switch 窗口会收起到系统托盘，继续提供连接。通过托盘可快速开启／关闭、在服务关闭时多选配置，或者重新打开主界面。详见[托盘快速操作](/docs/switch/#托盘快速操作)。

需要完全退出时，右键点击托盘图标，选择「退出应用」，或在设置中选择「完全退出 Codex Switch」。使用本地路由的 Codex 仍在运行时，会提示先退出 Codex。正常完全退出会先恢复原配置；恢复失败时会保留后台连接并显示原因。

## 未找到 Codex

先安装官方应用，再到设置中重新检测。Windows 安装路径与应用分发方式可能不同，尚待完整实机验证。
