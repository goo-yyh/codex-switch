## 一键打开

保存配置后，在首页勾选需要的配置并开启总开关，再点击「打开 Codex」。打开按钮只启动应用；开启期间的勾选变更直接应用，配置内容需关闭后编辑。macOS 按应用标识查找，避免仅凭应用文件名判断。

## 配置更新后

切换生效后，新旧会话经过本地路由的后续请求使用当前配置。Codex 界面的模型列表可能仍来自内存中的旧目录，可以在当前任务完成后正常重启刷新。关闭后恢复的原设置也可能需要重新打开才能读取。

重启前会检查本地路由是否有请求进行中。存在请求时会阻止重启。即使请求计数为零，Codex 仍可能在执行本地工具，因此你仍需要先确认任务结束。

重启只请求应用正常退出。若应用拒绝退出或超时，操作会停止，提示手动退出；不会强制终止进程。

## 关闭窗口与完全退出

关闭 Codex Switch 窗口会收起到系统托盘，继续提供连接。通过托盘可快速开启／关闭、切换到某个配置的全部模型，或者重新打开主界面。详见[托盘快速操作](/docs/switch/#托盘快速操作)。

需要完全退出时，右键点击托盘图标，选择「退出 Codex Switch」，或在设置中选择「完全退出 Codex Switch」。使用本地路由的 Codex 仍在运行时，会提示先退出 Codex。正常完全退出会先恢复原配置；恢复失败时会保留后台连接并显示原因。

## 未找到 Codex

先安装官方应用，再到设置中重新检测。Windows 安装路径与应用分发方式可能不同，尚待完整实机验证。
