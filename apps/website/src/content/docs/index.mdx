## 主要功能

- **连接多个服务**：支持智谱 GLM、DeepSeek、Kimi、千问、MiniMax，以及套餐和自定义 API。
- **一个 Key，多个模型**：每个配置可选多个模型，也能同时开启多个配置。
- **开启备份，关闭恢复**：修改设置前先关闭服务，不改变 Codex 的登录和会话记录。
- **本地管理**：Key 保存在系统凭据库，请求从本机发往你选择的服务。
- **中英文切换**：应用和文档均支持双语，应用记住上次选择。
