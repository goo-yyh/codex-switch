## Key features

- **Multiple providers:** connect Zhipu GLM, DeepSeek, Kimi, Qwen, MiniMax, plans and custom APIs.
- **One key, multiple models:** choose several models per configuration and enable multiple configurations together.
- **Automatic recovery:** back up before enabling and restore when disabling. Turn off the service before editing. Codex login and session files stay unchanged.
- **Local management:** keys stay in the system credential store; requests go from your device to your chosen provider.
- **Chinese and English:** both the app and docs support two languages. The app remembers your choice.

## Before you start

v0.1.0 is available for macOS (Apple Silicon and Intel) and Windows x64. See [installation](/en/docs/install/) for setup and unsigned installer notes. The app targets Codex App. CLI and IDE extension compatibility is not guaranteed.

The project references and reuses parts of CC Switch. See [open-source credits](/en/docs/open-source/). Codex Switch is an independent community project, unaffiliated with OpenAI.
