Codex Switch references and directly reuses parts of [CC Switch](https://github.com/farion1231/cc-switch). Thank you to Jason Young and the community contributors.

## Code origins

Reused code includes Chat / Responses conversion, streaming, tool-call history and model catalogs. Codex Switch independently maintains its desktop interface, configuration management, backup and recovery, and documentation.

The pinned upstream revision is [`06082e1`](https://github.com/farion1231/cc-switch/tree/06082e189d65e6d6dbadc35dacdac1ce6c79d89a). See [UPSTREAM.md](https://github.com/goo-yyh/codex-switch/blob/main/crates/cc-switch-codex/UPSTREAM.md) for full attribution and local differences.
