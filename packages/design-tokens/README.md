# Codex Switch 配色

官网与文档使用 `tokens.css` 中的蓝紫品牌色。App 在本地样式中覆盖中性色和主操作色，配合精简单列首页。

- App 页面：`#f7f9fb`；面板：白色；文字：`#252b34`。
- 主按钮：浅蓝 `#d4edff`，悬停 `#c0e4fc`，文字 `#263f51`。
- 已选连接：`#eef7fd`；分隔线：`#e4e9ee`。
- 深色模式跟随系统；品牌图标保留原图颜色，不全局反色。
- 服务商标识来自 `packages/brand/providers/`，按稳定 ID 匹配。
- 官网 App 示意采用与 App 相同的列表结构和主按钮色。

样式调整使用浏览器内存预览检查，不启动真实 Codex 或访问用户配置。
